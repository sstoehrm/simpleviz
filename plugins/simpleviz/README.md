# simpleviz plugin

The skill that teaches an AI assistant (Claude Code, Codex, Grok) the
[simpleviz](https://github.com/sstoehrm/simpleviz) graph format: writing
nodes, edges and boxes as EDN and docs and slides as markdown, then
serving, checking, comparing and presenting them.

It drives the `simpleviz` command, which it doesn't install; see the
[README](https://github.com/sstoehrm/simpleviz#readme) for that and
[Diagrams](https://github.com/sstoehrm/simpleviz/blob/main/docs/diagrams.md)
for the full data format. MIT licensed (see LICENSE).
